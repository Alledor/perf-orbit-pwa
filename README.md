## 🌌 Why Troff Zenith Exists

The web in 2026 is not the web of 2016. Users expect instant paint, offline resilience, installable experiences, and a feeling that applications live *inside* the device rather than lagging somewhere behind it. Progressive Web Apps carry enormous promise — yet the promise collapses silently when audits are shallow, tooling is fragmented, or reports are written in the language of machines rather than the language of decisions.

Troff Zenith was born from a simple conviction: **a performance audit should feel like reading a weather map, not decoding a hex dump.** You should be able to glance, understand, act, and improve — in that order.

This repository houses:

- A modular audit engine that evaluates PWAs across rendering, caching, networking, and interactivity.
- A visualization layer that turns metrics into stories, timelines, and heatmaps.
- A recommendation oracle that explains *why* something is slow, not merely *that* it is slow.
- Tooling designed to slot into 2026-era workflows: edge runtimes, streaming SSR, and AI-assisted refactoring pipelines.

## 🧠 Core Philosophy

Troff Zenith approaches audits through four metaphors:

1. **The Lighthouse That Doesn't Sleep** — continuous observation instead of one-shot scoring.
2. **The Weight Lifter's Ledger** — every kilobyte logged, every asset weighed, every dependency questioned.
3. **The Conductor's Baton** — orchestrating service workers, cache strategies, and prefetching into a single rhythm.
4. **The Zen Garden** — simplifying relentlessly, pruning the unnecessary, until only speed remains.

Each metaphor maps to a concrete module in the toolkit. Together they form a philosophy of **measured clarity**.

## 🧱 Performance Pillars

Troff Zenith organizes audits into seven pillars, each scored and explained:

1. **Paint & Perception** — first contentful paint, largest contentful paint, visual stability.
2. **Interaction Latency** — input responsiveness, long task detection, main thread contention.
3. **Asset Economy** — image formats, font loading strategies, compression opportunities.
4. **Network Choreography** — request waterfalls, HTTP/3 readiness, prefetch discipline.
5. **Cache Intelligence** — service worker strategy correctness, cache invalidation hygiene.
6. **Installability & Offline** — manifest quality, install prompt flow, offline fallback richness.
7. **Accessibility & Usability** — contrast, focus order, screen reader friendliness as performance for humans.

Each pillar produces a narrative summary alongside raw numbers.
